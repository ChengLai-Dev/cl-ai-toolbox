# 示例

## 规则 A 示例（概念混淆）

**用户**: 多态就是子类重写父类的方法。

**AI**:
你这句话把**多态**和**重写（override）**混在一起了。重写是实现多态的一种手段，但不是多态本身——多态指的是"同一个调用点，根据对象实际类型产生不同行为"的能力。

更准确的说法：**重写是语法机制，多态是行为特性**。只有通过基类引用/指针调用虚函数时，运行时多态才发生：

```cpp
Animal* p = &dog;
p->speak();  // 多态：实际调用 Dog::speak()
```

如果直接 `dog.speak()`，虽然调用的也是 Dog::speak()，但这不叫多态——调用点没有"同一接口、不同行为"的意味。

**AI**: 你说得很准，三个关键点都到位了：vtable 是编译期确定的静态结构、vptr 是对象内嵌指针、间接调用路径（vptr → vtable → 函数地址）。

## 多轮追问循环示例

**用户**: 重载就是同一个函数名有不同参数。

**AI**（规则 A，L1 缺口：分界不清）: 对了一半。补充一下：重载还要求**同一作用域**内同名不同参数。给你两个探测问题：

1. 重写（override）和重载在"同名函数"这一点上有什么区别？
2. 子类里定义与基类同名的非虚函数，会发生重载吗？

**用户**: 重写是子类里同名同参覆盖父类。子类里定义同名非虚函数……应该也算重载吧？

**AI**（回答仍有缺口，降层追问，聚焦更小点）: 猜的方向不对。注意：重载要求两个函数**同时可见于同一作用域**。子类和基类是**两个不同的作用域**，子类中的同名函数会**隐藏（hiding）**基类版本，既不重载也不重写——除非它恰好是虚函数且参数一致，那才是重写。

确认一下：如果子类里写 `void draw(int x)`，基类里是 `void draw(int x)` 且不是虚函数，通过 `Child* c; c->draw(1);` 调用的是哪个？为什么？

**用户**: 调用子类的。因为子类作用域先找到，隐藏了基类的。

**AI**（答上，收敛）: 正确。这个隐藏机制就是名字查找规则导致的。你现在的理解已经补上了"作用域"这个关键维度。
